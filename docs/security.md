# 보안 운영 기준

- `.env` 권한은 `600`으로 유지하고 비밀번호·API 키·관리 토큰을 출력하지 않는다.
- 공개 API와 내부 API는 `127.0.0.1`에만 바인딩한다. 외부 공개 시 TLS·인증 reverse proxy를 둔다.
- 내부 API는 32자 이상 Bearer token을 요구하며 브라우저 저장소에 토큰을 보관하지 않는다.
- 후보 데이터는 비공개로 반입하고 검토자가 승인하면서 공개를 명시한 경우만 노출한다.
- Export는 공개·검토 완료 데이터만 포함하고 CSV 수식 실행을 차단한다.
- 백업 비밀번호는 프로세스 환경으로만 전달한다. 백업 파일은 접근 권한이 제한된 저장소로 별도 복제한다.
- 의심되는 자격증명 노출이 발생하면 즉시 교체하고 관련 서비스를 재시작해 연결을 확인한다.
