## 집계·도구 수정

- 0030_capacity_hierarchy: 센터→프로젝트→Phase 용량 반영. 같은 항목/운영단계에 센터 총량이 있으면 우선 사용하고, 없으면 프로젝트 총량, 그마저 없으면 Phase 합계 사용. 상위 총량과 하위 용량을 중복 합산하지 않는다.
- 공개 승인 원문이 있는 확정 용량만 집계. 비공개 프로젝트·미검증 Phase·기한 만료·집계 제외·계약/가용 측정기준은 총 IT/수전 합계에서 제외한다. 비공개 최신 기록이 공개 기록을 가리지 않도록 필터 순서를 수정했다.
- 사실 반입 도구의 문서 연결을 실제 document_version_id 스키마에 맞추고 현재 버전 없는 문서 반입을 차단했다.
- YYYY-Qn RFS 분기를 인식하도록 수정했다.
- 시장 근거 화면: 유형별 필터, 실제 소스 기여도, 문서 미확보/수동/유료 미취득 상태, 필드 확보율, 재검토 근거 표시.
- 센터 상세: 시설·일정 근거 탭에서 설계 PUE, 인증 범위, 월 단위 서비스 개시와 원문 확인일 제공.
- 일일 공개 데이터 생성에도 소스 기여도·확보율 점검을 포함했다. 재검토 일자와 데이터 집계 생성 일자를 구분한다.
