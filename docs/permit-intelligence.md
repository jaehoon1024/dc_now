# 인허가·전력 참고자료 수집과 대시보드 반영

## 반영 범위

NamePF 공개 사실값을 정규화하고 기존 센터 원장에 대조해 시장 대시보드에 제공한다. 데이터의 출처·기준일·수집 결과를 표시한다. 원장의 상용 확정 상태, 용량, 운영/RFS를 일괄 변경하지 않는다.

2026-10-13 확인 결과:

| 항목 | 결과 |
|---|---:|
| 인허가 행 | 138건 |
| 대지 식별자 | 121종 |
| 착공 전 / 공사 중 / 사용승인 | 49 / 47 / 42건 |
| 단일 원장 주소와 일치 | 20건 · 17센터 |
| 이름만 대조 가능 | 5건 |
| 동일 주소에 복수 원장 | 10건 |
| 원장 연결 필요 | 103건 |
| 행정구역 대표점 | 138건 |
| 면적 집계 대조 대상 | 54건 |

허가·건물·대지·캠퍼스는 서로 다른 단위다. 위 행 수를 센터 수에 추가하거나 발표 MW를 시장 공급에 바로 합산하지 않는다. 원장 연결은 공개 스냅샷 기준이며 개인 수정안의 주소 변경과는 별도다.

## 수집과 저장

- 공개 입력: `https://dc.namepf.com/data/dash.json`.
- 정규화: `namepf_normalize.py`. 날짜, 미확인/0, IT/수전/분류 미확인 MW, 대표점, 면적 불일치를 보존한다.
- 갱신: `.venv/bin/python src30_collect_permit_intelligence.py`.
- 파일: `data/reference/namepf_intelligence.json`. 사실값과 출처 메타데이터만 저장하며 기사 본문·지도 도형·케이블 경로는 복제하지 않는다.
- 주소 대조와 전력 계산: `permit_intelligence.py`.
- 게시 스냅샷: `src21_build_static_site.py`가 `development_intelligence`를 추가한다.

이 자료는 SQL `dc_site` 및 `collection_run`과 별도로 관리되는 공개 참고 데이터다. 사용자에게 이 파일 갱신을 SQL 원장 승인·등록 완료로 보고하지 않는다. 원문으로 검증한 값의 원장 반영은 기존 검토·버전·감사 흐름을 사용한다.

## 정기 게시

기존 `dc-dashboard-publish.timer`의 매일 09:10 KST 실행에서 `src22_publish_dashboard.py`가 참고자료 수집 → 공개 API 스냅샷 취득 → 화면 빌드 → GitHub Pages 게시를 순서대로 수행한다. 새 참고 파일과 화면 스크립트도 게시 커밋 대상에 포함한다.

한 번의 갱신에 공개 JSON 한 건을 요청한다. 응답 크기와 스키마, 수집 완전성, 외부 허가 ID를 확인한다. 실패·불완전·빈 응답은 마지막 정상 자료를 보존하고 `FAILED_KEPT_PREVIOUS`로 표시한다. 정상 이력이 전혀 없으면 발행을 중단한다. 36시간 이상 수집 확인이 없으면 공개 화면에서 지연을 표시한다. API 키·DB 접속정보·환경 파일을 읽지 않는다.

## 화면

- 인허가 KPI와 연도별 허가/착공/사용승인 사건 차트.
- 건축 단계, 지역·검색, 원장 연결, 허가 연도 필터 및 CSV.
- 출처·용량 기준·날짜·면적·좌표 정밀도·관련 기사 상세.
- 연결 센터 상세로 이동, Google 주소 조회.
- 개인 브라우저 검토메모. 메모는 공유 원장이나 게시 데이터에 포함하지 않는다.
- 주소로 연결한 인허가를 기존 센터 상세에 표시.
- 지역별 정보통신업 평균 MW, 발전/판매 기준 자립도, 관할 변전소 그룹 여유.

전력 사용량 평균은 해당 12개월 kWh 합계 ÷ 실제 시간 합계 ÷ 1,000이다. 자료가 비거나 기간이 이어지지 않으면 외삽하지 않는다. 전국 여유는 동일 변전소 그룹을 한 번만 집계한다. 여러 지역 관할 합계는 중복될 수 있으므로 합산하지 않는다. 원출처 합산 권역인 전남·광주는 표시를 유지한다. 지역 지표를 센터의 IT Load·확보 전력·Available Capacity로 간주하지 않는다.

## 검증

111개 Python 테스트 중 95개 통과, 실제 DB 테스트 16개는 이번 실행에서 제외했다. 신규 검증은 주소 일치/복수 캠퍼스, 이름 힌트, 원장 불변, 미확인/0, 사용승인/RFS, 대표점, 전력 환산·중복 제거, 불완전 응답·수집 실패 유지다. 브라우저에서 인허가 필터·차트 키보드·상세·메모·센터 이동·CSV·지역 전력·390px·실패 상태를 확인했다.

용도지역, 용적률, 읍면동·리, 대장 변경일, 엑셀 표기 비중과 원본 행·자료 수집 시각을 보완한다. 용량의 IT/수전/기준 미표기 구분을 유지하며 반올림 비중을 면적 계산 비중에 덮어쓰지 않는다. 사용자 제공 파일은 기존 NamePF 자료와 같은 출처의 내보내기이므로 독립된 교차검증 소스로 간주하지 않는다. 원본 XLSX를 재게시하지 않고 사실값과 메타데이터를 공개 참고 원장에 저장한다.

- 가져오기: `.venv/bin/python src31_import_permit_workbook.py /path/to/permit-list.xlsx`.
- 보완 파일: `data/reference/permit_workbook_20261014.json`.
- `permit_workbook.py`가 날짜·숫자·안전한 출처 링크·중복 허가를 정규화한다. 수식은 실행하지 않으며 값만 있는 내보내기를 받는다.
- 정기 원자료 수집은 기존 `namepf_intelligence.json`을 갱신한다. 빌드 시 보완 파일을 외부 허가 ID로 재연결하므로 다음 수집에서 보완 정보가 사라지지 않는다.
- 현재 자료가 첨부 자료와 달라지면 차이를 표시하고 최신 원자료를 유지한다. 삭제된 허가를 엑셀로 다시 생성하지 않는다.
- 보완 값은 인허가 상세·센터 상세의 연결 인허가·CSV에서 확인할 수 있다. SQL 센터 승인, 실제 RFS, 센터 확보 전력으로 자동 변경하지 않는다.
