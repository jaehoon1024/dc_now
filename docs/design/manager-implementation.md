# 담당자 화면 구현 현황 — 2026-10-13

## 시장 대시보드 첫 화면

공개 첫 화면은 `market.html`로 전환했다. 운영·개발 4개 KPI, Phase/RFS 공급 전망, Google 지도, 센터 원장, 지역/운영사별 공급, 정보 확보율, 근거 및 수집 상태를 한 페이지에 제공한다. 지역·검색·단계·공급 연도·검증/추정 기준을 집계와 원장에 같이 적용한다. 센터 선택 시 우측 상세 패널이 열리고 키인 수정 화면으로 바로 이동한다.

`manage.html`은 기존 업무 기능을 유지한다. 이전 `#detail/...` 등의 링크는 관리 화면으로 연결한다. 관리 화면에서 저장한 브라우저 수정안은 시장 대시보드에도 반영한다. 공개 수정안과 인증된 공유 원장 저장은 기존 권한과 이력을 유지한다.

## 인허가·전력 데이터 확장

`development.js`에서 인허가 138건의 건축 단계, 121종 대지 식별자, 원장 주소 대조, 출처 상세·개인 검토메모를 제공한다. 주소 일치 20건은 17개 센터 상세에 연결한다. 이름 힌트와 복수 원장은 대조 대상으로 표시한다. 지역 전력 지표는 원장 용량과 별도 표시한다. 수집·실패 유지·정기 게시와 집계 기준은 `docs/permit-intelligence.md`를 따른다.

|---|---|

| 개발 프로젝트 | 공개 승인 프로젝트·Phase와 예정/실제 RFS |

공개 첫 화면은 시장 현황이고, 내부 화면은 인증 후 검토 API에 연결하는 관리 작업공간이다. 공개 GitHub Pages는 조회와 개인 수정안을 제공한다.

## 집계 원칙

- 확정·공개된 상용 센터만 시장 용량에 포함한다.
- MIXED 캠퍼스의 운영·개발 MW는 각각 표시한다. 센터 자체는 1개다.
- 미확인 값은 `—` 또는 `미확인`이며 0으로 표시하지 않는다.
- Phase가 있으면 Phase를 분석 단위로 사용하여 프로젝트와 중복 합산하지 않는다.
- 같은 단위의 용량 이력은 최신 공개 근거를 우선하고 만료·집계 제외 값을 빼고 계산한다.
- 운영 및 실제 RFS 이력, 기한이 지난 예정 RFS는 미래 신규 공급 차트에서 제외한다.
- 필드 갱신 시각을 근거 재확인 시각으로 대체하지 않는다.

## 현재 데이터와 남은 연결

이번 공개 스냅샷에 Phase 4건이 포함되어 있다. Phase가 없는 사업은 프로젝트 기준을 표시한다.
Google 전체 원장 마커, 클러스터, 용량별 표시 크기, A/B 좌표 및 근사 좌표 구분을 구현했다. 공개 브라우저 설정이 연결되면 활성화된다. 기본 설정에서는 Google 주소 검색 지도를 이용한다. 설정 방법은 `docs/google-map-setup.md`를 따른다.
담당자 배정·검토 기한·수정 후 승인·보류·필드 변경의 자동 반영·고객 계약 데이터는 다음 데이터 모델 및 워크플로 확장 대상이다.

## 검증

- 이번 Python 실행: 111개 중 95개 통과, 실제 DB 테스트 16개는 제외.
- 공개되지 않은 프로젝트·미승인 Phase·내부 문서 용량이 공개 상세에서 제외됨을 확인.
- 오래된 검토 화면이 이미 처리된 레코드를 덮어쓰지 못함을 확인.
- JavaScript 집계 테스트: 범주·공개 범위, 병행 캠퍼스, 미확인/0, Phase 중복, 만료·제외 용량, 운영 RFS, 수집 지연.
- 브라우저에서 실제 공개 데이터로 모든 메뉴·검색·필터·비교·상세·공급·지도 및 390px 모바일 표시 확인.
- 내부 인증·승인 요청·감사 이력 갱신은 브라우저의 모의 쓰기로 검증. 실제 운영 레코드 승인/반려는 수행하지 않았다.

## 운영

자동 게시기는 시장 화면, 관리 화면, 지도 스크립트 및 공개 설정을 모두 게시 대상에 포함한다. 스냅샷 빌더는 실행 중인 공개 API의 `/data.json`을 사용하며 설정 파일이나 DB 접속 정보를 읽지 않는다. 공개 API 연결에 실패하면 발행을 중단한다.
변경한 내부/공개 API는 사용자 systemd 서비스를 재시작해 적용한다.
