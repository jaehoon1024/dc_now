# DC NOW — 운영·개발 현황 대시보드 재설계

작성: 2026-10-13 · 참고: [dc.namepf.com](https://dc.namepf.com/)

## 1. 새 컨셉

**국내 데이터센터의 운영 공급, 개발 파이프라인, 입지·전력 여건을 한 화면에서 읽고 센터 원장으로 내려가는 시장 현황 대시보드.**

첫 화면은 `국내 데이터센터 운영·개발 현황`으로 바꾼다. 관리 담당자는 시장 전체를 먼저 보고, 관심 지역·사업자·센터를 선택해 상세 근거와 수정 업무로 들어간다. 기존 `오늘의 업무`를 중심으로 한 설계에서 첫 화면과 탐색 순서를 다시 정한다. 이 문서가 새 시장 화면의 기준이며, 기존 설계의 권한·검토·변경 이력 규칙은 이어 쓴다.

## 2. 참고 화면에서 확인한 구조

2026-10-13 Chrome에서 실제 공개 화면을 확인했다. 화면의 문구와 수치는 참고 사이트의 표시 내용이며, 해당 사이트의 집계 정확성을 별도로 검증한 것은 아니다. 이번 시안에는 DC NOW의 기존 공개 스냅샷만 사용했다.

| 참고 화면 | DC NOW에 적용할 구성 |
|---|---|
| 밝은 회색 바탕, 흰 패널, 청색 계열 차트 | 보고서처럼 읽히는 밝고 간결한 화면. 큰 홍보 배너 없이 숫자·차트·원장에 면적 배분 |
| 상단 네 개 요약 지표 | 운영 센터, 개발 센터, 운영 IT Load, 개발 IT Load. 값 확보율과 추정 범위를 함께 표시 |
| 허가·착공·준공 연도별 차트 | 우선 기존 Phase/RFS 기반 신규 공급 전망. 인허가 데이터 확보 후 개발 활동 차트를 별도 추가 |
| 지도와 개발 추이 차트를 나란히 배치 | Google 지도와 공급 전망을 같은 높이로 배치. 지역·센터 선택을 원장과 연결 |
| 단계 필터와 검색이 있는 상세 인허가 표 | 운영·개발을 구분하는 센터 원장. 용량, RFS, 사업자, 주소, 근거 상태를 행 단위로 비교 |
| 전력 사용량, 자립도, 변전소 여유 | 전력·입지 분석 영역. 확보된 센터 수전용량과 새로 수집할 지역 전력 지표를 구분 |
| 최근 기사, 제도·일정 | 센터 관련 근거와 수집 상태. 향후 정부 원문 기반 제도 일정 추가 |
| 출처·정의·갱신 시점 설명 | 각 지표 가까이에 집계 범위와 마지막 갱신 시각 표시 |

참고 화면은 건축 인허가 대장을 중심으로 구성되어 있다. DC NOW의 센터·사업자·Phase 원장과 결합하려면 동일 대지의 여러 건물·허가, 증축, 대수선 등을 대조해야 한다. **건축허가 건수와 센터 수, 사용승인일과 RFS는 각각 별도 항목이다.**

## 3. 첫 화면 구조

```text
DC NOW  국내 데이터센터 운영·개발 현황                   갱신 시각
시장 요약 / 공급 전망 / 센터 위치 / 센터 원장 / 전력·입지 / 근거·수집
────────────────────────────────────────────────────────────────
상용·자체센터·전체 범위  지역  센터·사업자 검색  추정 포함/원문 검증
┌──────────────┬──────────────┬──────────────┬──────────────┐
│ 운영 센터    │ 개발 센터    │ 운영 IT MW   │ 개발 IT MW   │
│ 범위·시점    │ 단계·RFS     │ 확보율·추정  │ 확보율·추정  │
├────────────────────────────┼────────────────────────────┤
│ 연도별 신규 공급 전망      │ Google 지도 · 지역 선택    │
│ Phase → RFS → IT Load      │ 센터 선택 → 주소·상세      │
├────────────────────────────┴────────────────────────────┤
│ 센터 원장: 전체 / 운영 / 개발 / 운영·증설 / 미확인       │
│ 센터·사업자 | 주소 | 단계 | IT | 수전 | RFS | 근거       │
├────────────────────────────┬────────────────────────────┤
│ 지역별 IT Load             │ 운영사별 포트폴리오        │
├────────────────────────────┼────────────────────────────┤
│ 전력·위치 정보 확보 수준    │ 전력·인허가 데이터 확장    │
├────────────────────────────┼────────────────────────────┤
│ 최근 수집 근거             │ 수집·원문 확보 현황        │
└────────────────────────────┴────────────────────────────┘
센터 선택 → 우측 상세 패널 → Phase·근거 확인 → 담당자 수정
```

상단 메뉴는 같은 페이지 안에서 이동한다. 상시 왼쪽 메뉴 대신 더 넓은 차트·원장을 제공한다. 관리 업무의 승인·반려, 개인 수정안, 공유 원장 저장, 발행은 기존 관리 화면에 연결하고 이후 동일 상세 패널로 통합한다.

## 4. 조회와 집계 규칙

- 기본 관리 범위는 상용 데이터센터. 클라우드·IT 자체센터, 기업 전용, 전체 추적 대상도 조회할 수 있다.
- 운영, 개발, 운영·증설 병행, 미확인을 구분한다. 병행 센터는 운영/개발 분석 각각에 포함될 수 있지만 전체 센터 수에서는 한 번만 센다.
- 지역·검색·단계 필터는 요약, 차트, 원장에 같은 기준으로 적용한다. 연도 막대를 누르면 해당 RFS에 연결된 센터를 조회하고 다시 누르면 해제한다.
- 초기에는 추정을 포함한 작업값으로 표시한다. 필드별 `검증값 / 발표값 / 추정 / 담당자 입력 / 수정안`과 근거를 유지한다.
- 원문 검증 보기에서는 미확인을 `—`로 표시한다. 미확인 용량을 0으로 합산하거나 전체 시장 공급이 없는 것으로 표현하지 않는다.
- 용량 KPI에는 값 확보 센터 수, 원문 검증 센터 수, 작업 범위를 표시한다. 모델 추정 합계는 시장 실측 총량과 구분한다.
- 신규 공급은 공개 근거가 연결된 상용 사업의 Phase/RFS 기준이다. 실제 가동, 기한이 지난 예정 일정, 취소·보류 사업은 미래 신규 공급에서 제외한다.
- 캠퍼스 전체 IT Load를 Phase마다 복제하지 않는다. 모든 Phase의 용량·일정이 확보되기 전에는 개발 총량과 연도별 공급 차트 합계가 다를 수 있다.
- 복수 운영사가 연결된 센터는 사업자 포트폴리오에 각각 표시될 수 있다. 사업자 막대 합계를 전국 총량으로 사용하지 않는다.
- 계약·LOI·예약의 범위와 시점이 확보되지 않으면 Available Capacity와 가동률은 계산하지 않는다.

## 5. 센터 원장과 상세 패널

### 원장

센터·운영사, 지역·주소, 단계, 운영/개발 IT Load, 운영/개발 수전용량, 다음 RFS, 좌표 검증 상태, 마지막 갱신일을 표시한다. 기본 정렬은 개발 사업 우선이다. IT Load와 RFS 정렬, 검색, 페이지 이동, 현재 조건의 CSV 내보내기를 제공한다.

### 상세 패널

원장 행을 선택하면 기존 검색 결과를 유지한 채 우측 패널을 연다.

1. 센터명, 단계, 운영사, 운영/개발 용량, RFS.
2. 주소, 소유주, 개발사, 자산운용사, 시공사.
3. 프로젝트·Phase별 IT/수전, 준공, RFS.
4. 발표·추정·담당자 입력의 범위, 산정 방법, 원문 URL.
5. 검증한 항목과 확인일, 근거 문서.
6. 담당자 수정 화면으로 이동.

향후 편집 통합 시 숫자 바로 옆에서 필드 단위로 입력하고 근거·상태·수정자를 남긴다. 공개 화면의 개인 수정안과 인증된 공유 원장 저장은 서로 다른 행동으로 표시한다. 기존 버전 충돌 검사와 감사 이력을 유지한다.

## 6. 지도와 전력 레이어

지도는 Google 기반으로 유지한다. 실제 다중 마커 구현에서는 센터를 캠퍼스 기준으로 묶고 운영/개발 색상, IT/수전 규모, 위치 정밀도를 표시한다. 행정구역 대표점은 정확 좌표와 다른 표시를 쓰고, 좌표가 없는 대상은 목록에 유지한다.

| 레이어 | 필요한 데이터 | 적용 기준 |
|---|---|---|
| 센터·캠퍼스 | 기존 좌표·주소·단계·용량 | 주소 조회 결과와 DB 좌표 검증을 구분 |
| 건축 인허가 | 건축HUB/세움터 허가·착공·사용승인 | 대지·건물·변경 허가를 센터/Phase와 대조 |
| 변전소 공급 여유 | 한전 공개 여유 지도·기준 시점 | 광역 지역에 중복 표시되는 변전소는 ID로 중복 제거 |
| 전력 확보 | 센터 공식 수전·계약·계통평가 근거 | 지역 공급 여유를 센터 확보 전력으로 대체하지 않음 |
| 지역 전력 수요 | 한전 산업분류 사용량·전력거래소 지역 지표 | 정보통신업 사용량과 DC 전용/IT Load를 구분 |
| 제도·입지 | 정부 고시·법령·지정 원문 | 발의·공포·시행·지정을 별도 상태로 기록 |

이번 시안은 선택 센터 주소를 Google iframe으로 조회한다. 전국 다중 마커, 클러스터와 레이어 기능은 Google Maps API 및 도메인 제한 설정 후 개발할 범위다. 추가 전력·인허가 데이터는 아직 연결되지 않았으며 확보한 값처럼 표시하지 않는다.

## 7. 시각 기준

- 밝은 회색 배경, 흰 패널, 얇은 회색 경계. 청색을 중심으로 운영/개발/병행 상태 구분.
- 상단 4개 KPI, 그 아래 차트·지도 1:1. 센터 원장은 전체 너비로 배치.
- 제목, 수치, 단위, 근거 설명의 크기를 분리하고 표는 12px 이상으로 유지.
- 과도한 카드·아이콘·배경 장식을 줄이고 동일한 패널 규칙을 반복한다.
- 모바일에서는 KPI 2열, 차트·지도 1열. 원장은 가로 스크롤하고 상세 패널은 전체 화면으로 연다.
- 버튼, 라디오, 검색, 정렬, 차트 선택은 실제로 동작한다. 미구현 데이터 연결은 수집 설계로 명시한다.

## 9. 후속 개발 반영 — 2026-10-13

시장 대시보드를 공개 첫 화면으로 구현했다. 기존 관리 업무는 `manage.html`로 연결한다. 개인 수정안 동기화, 이전 상세 링크, 키인 수정 탭 직접 접근, 모바일 상세를 검증했다. Google 전국 마커·클러스터·용량 크기·좌표 등급 필터 코드는 구현했으며 공개 지도 설정 연결 후 활성화된다. 현재는 주소 조회 지도다. 건축 인허가·변전소 데이터 수집은 후속 작업으로 남아 있다. 실제 구현 현황은 `manager-implementation.md`, 지도 설정은 `../google-map-setup.md`를 따른다.
