# 소스 기여도와 직접 수집 — 2026-10-16

## 기여도

- 확보 문서: 기존 SQL evidence_document의 ACTIVE 건수. 최근 7일은 문서 생성일 기준.
- 공개 확정 문서: PUBLIC 및 CONFIRMED인 문서. 신규 직접 수집 문서는 CANDIDATE로 유지한다.
- 확정 사실: 공개 확정 문서 버전과 fact_evidence로 연결된 CONFIRMED fact_id를 소스별 중복 제거.
- 확정 용량: 공개 확정 문서의 원문 URL에 연결된 CONFIRMED capacity_id를 소스별 중복 제거. 복수 소스가 같은 사실을 뒷받침할 수 있으므로 소스별 수치를 무조건 합산하지 않는다.
- 간접 인허가: 건축HUB 원출처의 NamePF·첨부 경유 138행을 별도로 표시한다. 직접 API 문서 수·상용 센터 수에 더하지 않는다.

등록 상태만으로 수집 연계를 판단하지 않는다. source_feed/source_page의 활성 경로·실패 횟수·성공 시각, OpenDART 실제 실행, 공식 시설 안내 실행 기록을 사용한다. 미연결·수동 취득·계약 필요·비활성·실패·연결을 구분하고 상태 필터와 원인 펼치기를 제공한다.

## 공식 시설 안내

`official_collection.py`는 `official_collection_catalog.json`에 검토한 8개 공식 주소의 제목·링크만 수집한다. 기존 뉴스룸 서비스가 이어서 실행하며 기존 요청 간격과 robots 지침을 따른다. 본문은 저장하지 않고 확인하지 않은 MW·주소·RFS를 추출하거나 자동 승인하지 않는다.

공식 사이트 정책을 확인하고 연결한 소스는 SOURCE_REVIEW 감사 이력에 기록한다. 새 문서는 WEB_PAGE 유형이며 같은 소스·원문 URL의 기존 문서를 중복 생성하지 않는다. 자동 수집한 문서의 제목 변경은 기존 버전 관리 경로를 사용한다. 수동 검토한 기존 문서는 임의로 덮어쓰지 않는다.

2026-10-16 최초 실행: 8곳 중 6곳 정상, 신규 문서 5건. 가비아 robots 경로가 공식 오류 안내로 전환되고 유효한 규칙 파일이 없는 것을 확인한 후, 검토한 정확한 전환 경로만 허용했다. 재실행 결과 7곳 정상, 추가 신규 1건으로 이번 작업의 신규 문서는 총 6건이다. 드림마크원은 로컬 TLS 검증에서 인증서 체인 오류가 남아 있으며 TLS 검증을 해제하지 않는다.

`OFFICIAL_REFERENCE_DAILY` collection_run 및 `official_collection_latest.json`에서 실제 성공·실패·오류 코드를 확인한다. 실패해도 기존 DB 문서는 보존하며, 실패를 연결 성공으로 표시하지 않는다.

## 뉴스 수집 범위

뉴스룸 목록 조회 상한을 3페이지에서 6페이지로 늘렸다. 실제 확인 페이지 수·목록 최저 날짜·중단 사유를 `newsroom_coverage_latest.json`에 기록한다. 페이지 상한 확대를 과거 3년 전수 수집 완료로 간주하지 않는다.

데이터센터코리아는 전시회·행사 안내, 메일리는 주간 뉴스레터, 딜북은 RSS 최근 기사 범위라는 설명을 추가했다. 공식 API 수집기나 계약이 없는 출처는 각각 미연결·계약 필요 상태로 유지한다.
