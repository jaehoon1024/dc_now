# 상용 데이터센터 정보 소스 검토

검토일: 2026-10-04
대상: 국내 코로케이션, wholesale, master lease, 임차 운영, build-to-suit 및 managed service 데이터센터

## 결론

기존 구성은 뉴스 탐색에는 충분하지만 센터를 확정할 1차 자료가 부족하다. 앞으로는 한 소스로 센터를 확정하지 않고 아래 순서로 결합한다.

1. 디렉터리·뉴스·시장보고서로 후보를 발견한다.
2. 사업자 공식 시설 페이지나 팩트시트로 상용 서비스와 운영 주체를 확인한다.
3. 건축HUB·EIASS·지자체 고시로 주소와 개발 단계를 확인한다.
4. OpenDART·KIND·리츠정보·해외 공시로 투자자, AMC, 임차, PF와 거래를 확인한다.
5. Uptime·NVIDIA와 사업자 사양서로 Tier, GPU 및 냉각 정보를 확인한다.

공개 Market KPI에는 `IN_SCOPE + CONFIRMED`만 반영한다. 디렉터리와 기사만 있는 시설은 `REVIEW_REQUIRED + NEEDS_EVIDENCE`로 유지한다.

## 자동수집 판단

| 방식 | 대상 | 판단 |
|---|---|---|
| 즉시 자동수집 | OpenDART, 승인된 RSS, SEC EDGAR | 공식 API/RSS 정책과 호출 제한을 준수하면 가능 |
| API 키 준비 후 자동수집 | 건축HUB 인허가·대장, 리츠정보, 토지 실거래 | 공공데이터포털 활용신청과 키 등록 필요 |
| 조건 검토 후 자동수집 | EIASS Open API, 사업자 뉴스룸·시설 페이지 | 약관·robots·응답 구조를 소스별로 승인해야 함 |
| 수동 검토 | 시장보고서 PDF, 사업자 팩트시트, 지자체 심의자료 | 사실값·URL·확인일만 구조화하고 원문 복제 금지 |
| 자동수집 금지 | PeeringDB, 로그인·유료·계약형 시장 DB | 라이선스 또는 서면 허가 전 저장·재배포 금지 |

## 이번 반영

- 공식 공공·규제 소스 8개를 등록했다.
- 상용 운영사·개발사 공식 소스 9개를 등록했다.
- 시장·인증·후보 탐색 소스 8개를 등록했다.
- 상용성, 개발단계, 임대·거래, 운영사, 공급망 전용 Google News RSS 5개를 추가했다.
- 기존 LG U+, KINX, Equinix, Digital Realty, KDCC, Uptime 등은 자동 크롤링 없이 수동 근거 소스로 활성화했다.
- PeeringDB는 정책상 `BLOCKED / NO_STORAGE`로 등록했다.
