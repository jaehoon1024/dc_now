# 현재 검증 범위 출시 준비 결과

- DB schema: Alembic 0015 head
- 수집: OpenDART, RSS, 승인된 기업 뉴스룸
- 자동화: 수집 3개, 실패 알림, 백업, 품질, 상태, 보존 preview
- 공개 기능: 지도, 센터 목록·상세, 지역·기업·연도 통계, CSV·GeoJSON
- 내부 기능: 기준 데이터 반입, 사실·근거 연결, 검토·감사, 품질 보고
- 보안: 로컬 바인딩, 관리 token, 비공개 후보 반입, 자격증명 교체
- 복구: 실제 custom-format 백업, SHA-256, pg_restore 목록 검증

현재 센터·프로젝트 기준 데이터가 0건이므로 운영 데이터 출시는 원본 파일 확보와 검토 후 수행한다. 외부 인터넷 공개에는 TLS reverse proxy와 접근 정책이 추가로 필요하다.
